# 🎓 SRM CGPA Calculator

A modern and responsive web application for SRM students to calculate CGPA, Percentage and Grade.

## ✨ Features

- Calculate CGPA from SGPA
- Percentage Conversion
- Grade Prediction
- Academic Performance Summary
- Responsive Design
- Modern Purple Glassmorphism UI

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
